#  Caesar Cipher CLI Program

A simple and robust Python command-line tool to encrypt, decrypt, and brute-force texts using the **Caesar Cipher** algorithm. Supports both English and Russian alphabets (including upper/lowercase letters and the Russian 'Ё').

---

##  Features

* **Dual Language Support:** Works seamlessly with English (26 letters) and Russian (33 letters) texts.
* **Full Case Preservation:** Maintains uppercase and lowercase distinction while ignoring punctuation, spaces, and numbers.
* **Brute-Force Cracking:** Includes a built-in brute-force mode to easily decrypt messages with unknown shifts.
* **Correct Russian Alphabet Mapping:** Handles 'Ё' / 'ё' correctly using a complete 33-letter alphabet.
